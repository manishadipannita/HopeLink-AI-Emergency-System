# 🆘 HopeLink AI Emergency Response System

## 📌 Overview

HopeLink is an AI-powered emergency response platform that analyzes crisis situations, identifies emergency types, determines severity levels, and recommends required support resources.

The system helps users receive quick safety guidance and connects them with necessary emergency services.

---

## ✨ Features

✅ AI-based Emergency Situation Analysis  
✅ Emergency Type Detection  
✅ Confidence Score Prediction  
✅ Severity Level Identification  
✅ Required Support Recommendation  
✅ Emergency Safety Tips  
✅ Volunteer Support System  
✅ Emergency Report Generation (PDF)  
✅ AI Response Guidance  

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Transformers (Hugging Face)
- PyTorch
- ReportLab
- HTML/CSS Styling
